# Huellitas · Landing para clínica veterinaria

Proyecto de portfolio creado por **La Trama**. Landing page de una clínica veterinaria ficticia en Sevilla, pensada como muestra de diseño web para clínicas reales.

> La clínica, sus datos de contacto, el equipo y las reseñas son inventados. Los formularios son de demostración y no envían datos.

## Qué incluye

- Hero con rótulo de marca a gran tamaño y mascota recortada
- Servicios, propuesta de valor y sección de seguimiento en directo
- Formulario de reserva con fecha, hora y tipo de mascota
- Preguntas frecuentes en tarjetas, reseñas y footer con boletín
- Diseño adaptado a móvil, tablet y escritorio
- Accesibilidad básica: navegación por teclado, menú móvil accesible, textos alternativos y respeto a `prefers-reduced-motion`
- SEO local: metadatos y datos estructurados `VeterinaryCare`

## Tecnología

Un único `index.html` con HTML, CSS y JavaScript sin dependencias. No necesita compilación: basta con abrir el archivo o servir la carpeta.

- Tipografías: Raleway y Amatic SC (Google Fonts). Los rótulos gigantes usan Raleway estática alojada en `assets/fonts/`.
- Imágenes en `assets/img/`.

## Verla en local

Abre `index.html` en el navegador.

## Publicar en GitHub Pages

En el repositorio: **Settings → Pages → Deploy from a branch → `main` / root**.

## Créditos de imágenes

Fotografías de mascotas de [Unsplash](https://unsplash.com) (licencia Unsplash). Los recortes del hero, la sección de transparencia y las reseñas se han hecho a partir de imágenes aportadas por La Trama.
